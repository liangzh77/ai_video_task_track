# Remix 成片投放效果数据回传 API

## 概述

将 Remix（R评级）成片的分天投放效果数据推送到接收方。仅推送有巨量视频映射且有投放记录的视频。

## 接口

### `POST {接收方URL}`

### 请求头

| Header | 值 |
|--------|------|
| Content-Type | application/json |

### 请求体

```json
{
  "sync_time": "2026-02-28T15:30:00",
  "videos": [
    {
      "video_id": 12187,
      "ocean_video_ids": ["7606309543139917867"],
      "daily": [
        {
          "date": "2026-02-27",
          "cost": 4443.41,
          "roi": 2.1,
          "impressions": 44317,
          "cpm": 100.27,
          "clicks": 1232,
          "ctr": 2.78,
          "cpc": 3.61,
          "conversions": 20,
          "cvr": 1.62,
          "cpa": 222.17
        }
      ]
    }
  ]
}
```

### 字段说明

#### 顶层

| 字段 | 类型 | 说明 |
|------|------|------|
| sync_time | string | 推送时间 ISO 8601 |
| videos | array | 视频数据数组 |

#### videos[n]

| 字段 | 类型 | 说明 |
|------|------|------|
| video_id | int | 成片ID |
| ocean_video_ids | string[] | 巨量引擎视频ID |
| daily | array | 分天投放数据 |

#### daily[n]

| 字段 | 类型 | 说明 |
|------|------|------|
| date | string | 日期 YYYY-MM-DD |
| cost | float | 消耗（元） |
| roi | float | ROI |
| impressions | int | 展示数 |
| cpm | float | 千次展示费用（元） |
| clicks | int | 点击数 |
| ctr | float | 点击率（%） |
| cpc | float | 点击单价（元） |
| conversions | int | 转化数 |
| cvr | float | 转化率（%） |
| cpa | float | 转化成本（元） |

### 期望响应

```json
{
  "success": true,
  "message": "成功接收 9 个视频的投放数据"
}
```

## 推送命令

```bash
cd /opt/xianban_feeds/backend

# 预览（不推送）
python3 scripts/push_remix_performance.py --dry-run

# 推送到测试端点
python3 scripts/push_remix_performance.py

# 推送到正式地址
python3 scripts/push_remix_performance.py --url https://对方域名/api/path
```

## 备注

- 仅推送同时满足三个条件的成片：R评级 + 有巨量视频映射 + 有投放记录
- CTR/CVR 为百分比值（如 2.78 表示 2.78%）
- ROI 为加权平均值：`sum(cost × roi) / sum(cost)`
- CPM/CPC/CPA 在分母为 0 时返回 0
